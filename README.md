pLM-Enhanced CATH Classification

TUM Informatics 12 - Chair for Bioinformatics
Team: Benedict Bode, Berra Madran, Marc Beil, Polina Yugantseva
Supervised by: Tobias Olenyi

We developed a deep learning model to classify protein domains in the CATH hierarchy using ProtT5 embeddings and CNN-based architectures inspired by ProtENN2. Our research explores how sequence-based language models can approximate structural classification.

* Developed two model architectures: a two-tier model with explicit boundary prediction and an all-in-one model predicting domain class per residue.
* Used ProtT5 per-residue embeddings to enhance prediction of CATH levels (Class, Architecture, Topology, Homology).
* Achieved competitive results compared to structure-based tools like Chainsaw and SWORD2.
